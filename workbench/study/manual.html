Patient actionRelease the shared call if calls agree. Retest if they disagree. The frozen margin is −1; every agreement passes.
After revealResponse 1 = responder, response 0 = non-responder. Count a wrong release when its released call differs from response. Retested patients contribute retest cost.
Two risks100 × wrong / all patients; 100 × wrong / released patients. Enter NA if released = 0.
Cost(wrong + 0.25 × retests) / all patients. Units are relative to one wrong release.

Score five baselines

Readout 1 alone and readout 2 alone each release every patient's own call. “Both sensitive” releases 1 only if both calls are 1; “Either sensitive” releases 1 if either call is 1. Each releases 0 otherwise. “Retest everyone” releases zero and costs 0.25 per patient. Count errors against the revealed responses and choose any tied lowest-cost baseline.

Spreadsheet starting point

With patient in A, R1 in B, R2 in C: D2 =--(B2<=0.7291000000000001); E2 =--(C2<=0.69765); action F2 =IF(D2=E2,D2,"retest"). Copy the formulas down. With revealed response in G, wrong-release H2 =IF(F2="retest",0,--(F2<>G2)). Use the sums and counts above for the batch.
