Review six patient batches.

You will use a manual worksheet for three batches and this tool for three. Each batch has six different patients. Allow about 20–30 minutes, including a practice review and breaks.

  1. Practise once. Open the workbench, choose “Explore a batch”, run “Predict actions”, review the list, and reveal outcomes. Use this practice before starting the study; the facilitator can use the separate seven-patient CSV in examples/new_batch_input.csv.
  2. Enter your assigned code. Open “Timed study”. Choose P01–P06 and your usual manual workflow. Researchers select “Researcher study”; facilitators and automated checks use their own record types.
  3. Start each task when ready. For a manual task, use your usual spreadsheet, paper or existing script with the provided frozen rule. For a tool task, press “Predict actions” and review its recommendations. Choose release-sensitive, release-resistant or retest for every patient.
  4. Lock, then reveal. Review the newly revealed outcomes. Report wrong releases divided by all patients, wrong releases divided by released patients, cost per patient, and the lowest-cost baseline. Tool tasks offer “Use calculated results”. Manual tasks use your own calculations; the revealed worksheet can be downloaded.
  5. Finish and return one file. Click “Finish task”, then start the next task. After all six, export the anonymous JSON record and send it to your facilitator. Use “Pause” for an interruption; both active time and total elapsed time are saved.

The question: does the tool help you produce a correct patient-action worksheet faster? The record includes coded decisions, changes, timing and final answers. It stays in this browser until you export it. Keep the tab open while working.

The data: previously published organoid measurements and known historical clinical outcomes, arranged as usability exercises. These decisions are for a research workflow replay. A retest costs 0.25 units relative to one wrong released call.
